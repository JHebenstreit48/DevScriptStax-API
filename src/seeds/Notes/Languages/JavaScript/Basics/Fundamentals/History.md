# How JavaScript Came to Be

<hr class="dividerSection" />

## The Birth of JavaScript

<hr class="dividerSection" />

In <span class="emphasis">1995</span>, <span class="emphasis">Brendan Eich</span> created the first version of JavaScript while working at <span class="emphasis">Netscape Communications</span>.

The goal was to develop a <span class="secondEmphasis">lightweight scripting language</span> that could run inside <span class="emphasis">web browsers</span> and enable greater <span class="secondEmphasis">user interactivity</span>.

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>JavaScript was originally called <span class="emphasis">Mocha</span> during early development.</li>
    <li>It was briefly renamed <span class="emphasis">LiveScript</span> before finally being released as <span class="emphasis">JavaScript</span>, to capitalize on the popularity of <span class="secondEmphasis">Java</span> at the time.</li>
    <li>Despite the name, <span class="emphasis">JavaScript</span> and <span class="secondEmphasis">Java</span> are fundamentally different languages with different purposes.</li>
  </ul>
</div>

<hr class="dividerSection" />

## Early Adoption and Standardization

<hr class="dividerSection" />

As JavaScript grew in popularity, <span class="emphasis">inconsistencies</span> appeared between <span class="secondEmphasis">browser implementations</span>.

To solve this, JavaScript was <span class="emphasis">standardized</span> under the name <span class="emphasis">ECMAScript</span> by <span class="secondEmphasis">Ecma International</span>.

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>The first standard, <span class="emphasis">ECMAScript 1</span>, was published in <span class="secondEmphasis">1997</span>.</li>
    <li>Over time, major updates like <span class="emphasis">ES5</span> (2009) and <span class="emphasis">ES6</span> (<span class="secondEmphasis">ES2015</span>) added powerful new features, including <span class="secondEmphasis">classes</span>, <span class="secondEmphasis">modules</span>, <span class="secondEmphasis">arrow functions</span>, and <span class="secondEmphasis">promises</span>.</li>
  </ul>
</div>

<hr class="dividerSection" />

## JavaScript's Growth Beyond the Browser

<hr class="dividerSection" />

Originally, JavaScript was confined to <span class="emphasis">client-side scripting</span> inside browsers.

With the creation of <span class="emphasis">Node.js</span> in <span class="secondEmphasis">2009</span>, JavaScript expanded to <span class="emphasis">server-side development</span> as well.

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li><span class="emphasis">Node.js</span> uses the <span class="emphasis">V8 JavaScript engine</span>, originally built for <span class="secondEmphasis">Google Chrome</span>.</li>
    <li>This made it possible to build <span class="emphasis">full-stack applications</span>, <span class="secondEmphasis">APIs</span>, and <span class="secondEmphasis">real-time applications</span> such as chat servers with JavaScript.</li>
  </ul>
</div>

<hr class="dividerSection" />

## JavaScript Today

<hr class="dividerSection" />

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>JavaScript remains the <span class="emphasis">dominant language</span> for <span class="secondEmphasis">web development</span>.</li>
    <li>It is one of the three core <span class="emphasis">front-end technologies</span>, alongside <span class="secondEmphasis">HTML</span> and <span class="secondEmphasis">CSS</span>.</li>
    <li>Frameworks and libraries like <span class="emphasis">React</span>, <span class="emphasis">Angular</span>, and <span class="emphasis">Vue.js</span> have further propelled its growth.</li>
    <li>JavaScript now powers <span class="secondEmphasis">client-side interfaces</span>, <span class="secondEmphasis">server-side APIs</span>, <span class="secondEmphasis">mobile apps</span>, <span class="secondEmphasis">desktop apps</span>, and even <span class="secondEmphasis">IoT devices</span>.</li>
  </ul>
</div>
