# What Is JavaScript?

<hr class="dividerSection" />

<span class="emphasis">JavaScript</span> is a <span class="secondEmphasis">dynamic</span>, <span class="secondEmphasis">high-level</span> programming language primarily used for creating <span class="emphasis">interactive and dynamic web applications</span>.

<span class="emphasis">JavaScript</span> serves as the <span class="secondEmphasis">brain</span> or <span class="secondEmphasis">nervous system</span> of a web page.

It provides the <span class="emphasis">logic</span> and extra functionality that enhances a webpage's <span class="secondEmphasis">interactivity</span> and <span class="secondEmphasis">user experience</span>.

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>Runs inside web browsers to manipulate <span class="secondEmphasis">HTML</span> and <span class="secondEmphasis">CSS</span>.</li>
    <li>Now also used outside browsers thanks to platforms like <span class="emphasis">Node.js</span>.</li>
    <li>Supports both <span class="secondEmphasis">object-oriented programming (OOP)</span> and <span class="secondEmphasis">functional programming</span> paradigms.</li>
    <li>Plays a critical role alongside <span class="secondEmphasis">HTML</span> and <span class="secondEmphasis">CSS</span> in the core technologies of web development.</li>
  </ul>
</div>

<hr class="dividerSection" />

### Key Characteristics of JavaScript

<hr class="dividerSection" />

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li><span class="emphasis">Interpreted Language</span> — Runs directly without needing prior compilation.</li>
    <li><span class="emphasis">Prototype-Based Inheritance</span> — Objects inherit directly from other objects.</li>
    <li><span class="emphasis">Event-Driven</span> — Designed to respond to user interactions dynamically.</li>
    <li><span class="emphasis">First-Class Functions</span> — Functions are treated as variables and can be passed as arguments.</li>
  </ul>
</div>

<hr class="dividerSection" />

### Example of Simple JavaScript Code

<hr class="dividerSection" />

```js
function greet(name) {
  console.log("Hello, " + name + "!");
}

greet("World"); // Output: Hello, World!
```

<hr class="dividerSection" />

### Why Use JavaScript?

<hr class="dividerSection" />

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li><span class="emphasis">Enhances Web Interactivity</span>, enables dynamic content like popups, forms, animations, and games.</li>
    <li><span class="emphasis">Full Stack Capabilities</span>, with Node.js, JavaScript can be used for both front-end and back-end development.</li>
    <li><span class="emphasis">Rich Ecosystem</span>, a vast number of libraries (like React, Angular, Vue) and frameworks help speed up development.</li>
    <li><span class="emphasis">Large Community Support</span>, active community with millions of developers and open-source contributions.</li>
    <li><span class="emphasis">Continuous Evolution</span>, new features added regularly via ECMAScript (ES6+ updates).</li>
  </ul>
</div>
