# What Is Netlify?

<hr class="dividerSection" />

Netlify is a cloud platform for building, deploying, and scaling modern web applications, letting you go from an idea to a live project without managing servers.

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>Founded in the summer of 2014 by <span class="emphasis">Mathias Biilmann</span> and <span class="emphasis">Christian Bach</span> to build a faster, simpler, and safer web. Headquartered in San Francisco with a global team.</li>
    <li>Used by over <span class="emphasis">10 million developers</span>, with more than <span class="emphasis">60 million apps deployed</span> on the platform.</li>
    <li>Runs on a global edge network with <span class="emphasis">99.99% uptime</span>.</li>
    <li>Home to projects ranging from solo builders to large enterprises running complex e-commerce and SaaS applications in production.</li>
  </ul>
</div>

<hr class="dividerSection" />

## Multiple Ways to Start a Project

<hr class="dividerSection" />

Netlify supports several starting points, so teams can build the way that fits them rather than being locked into one workflow.

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li><span class="emphasis">AI agent</span>, describe what you want to build and an agent handles the setup.</li>
    <li><span class="emphasis">Git</span>, connect a repository for continuous deployment, with every pull request getting its own preview URL.</li>
    <li><span class="emphasis">CLI</span>, deploy directly from a working directory with no login required to start.</li>
    <li><span class="emphasis">Drag and drop</span>, drop a project folder in and it is live within seconds.</li>
  </ul>
</div>

<hr class="dividerSection" />

## Why Teams Choose Netlify

<hr class="dividerSection" />

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>Every change gets a preview URL before it goes live, with one-click rollback for any past deploy.</li>
    <li>Agent-ready primitives, including serverless functions for APIs, instant databases and file storage, built-in identity for auth, and an AI Gateway that connects to OpenAI, Anthropic, and Gemini.</li>
    <li>Automatic HTTPS and DDoS protection, with access, secrets, and environment variables managed by team.</li>
    <li>Built for many kinds of projects, including AI apps, marketing sites, SaaS apps, e-commerce, and internal tools, all on the same underlying infrastructure.</li>
  </ul>
</div>
