# Pricing & Plans

<hr class="dividerSection" />

## Overview

<hr class="dividerSection" />

Render offers several pricing tiers ranging from a free tier for small projects to paid plans for production workloads.

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>The free tier is available for static sites, web services, and databases with limitations.</li>
    <li>Paid plans offer better performance, more resources, and no spin-down behavior.</li>
  </ul>
</div>

<hr class="dividerSection" />

## Free Tier Limitations

<hr class="dividerSection" />

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>Free web services <span class="emphasis">spin down after periods of inactivity</span>. The first request after spin-down triggers a cold start which can cause slow load times.</li>
    <li>Free PostgreSQL databases expire after 90 days.</li>
    <li>Limited bandwidth and build minutes per month.</li>
    <li>No support for persistent disks on free tier web services.</li>
  </ul>
</div>
