# Introduction to Render

<hr class="dividerSection" />

## What Is Render?

<hr class="dividerSection" />

<span class="emphasis">Render</span> is a cloud platform for deploying and hosting web applications, APIs, static sites, databases, and background workers.

It is designed to simplify deployment by connecting directly to your Git provider and automatically deploying whenever you push changes to your repository.

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>Supports static sites, web services, background workers, cron jobs, and managed databases.</li>
    <li>Deploys automatically from GitHub, GitLab, or Bitbucket on every push.</li>
    <li>No DevOps configuration required for basic deployments.</li>
    <li>Offers a free tier with limitations and paid plans for production workloads.</li>
  </ul>
</div>

<hr class="dividerSection" />

## Summary

<hr class="dividerSection" />

Render is a straightforward platform for getting web applications and services deployed quickly without manual server configuration.
